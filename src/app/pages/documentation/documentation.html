Intégrez PaySim
en 4 étapes

PaySim est une plateforme de paiement mobile Madagascar. Votre projet appelle un endpoint, génère un QR code, et écoute le hub SignalR — c'est tout.

Prérequis

Authentification

Chaque requête vers PaySim utilise une API Key que vous obtenez depuis votre tableau de bord développeur PaySim. Gardez-la secrète côté serveur.

⚠ N'exposez jamais votre API Key dans le code frontend. Faites l'appel /developer/info/setup uniquement depuis votre backend.
Étape 1

Créer un paiement

Avant d'afficher quoi que ce soit à l'utilisateur, votre backend doit créer une session de paiement. PaySim vérifie votre API Key, enregistre la commande et retourne une valeur QR.

POST https://paysim.runasp.net/developer/info/setup

Corps de la requête

JSON 
{{ '{' }}
  "apiKey": "VOTRE_API_KEY",
  "idOrder": "CMD-001",
  "totalprice": 5000,
  "infoNumber": "yas",
  "email": "client@email.com"
{{ '}' }}
ChampTypeDescription
apiKeystringVotre clé API projet
idOrderstringIdentifiant de votre commande interne
totalpricedecimalMontant en Ariary
infoNumberstring"yas" / "org" / "air" — opérateur mobile money
emailstringEmail de l'acheteur (facultatif)

Réponse (200 OK)

JSON 
{{ '{' }}
  "valueKey": "id:XXXX/id_proj:XXXX/actionkey:CMD-001/reason:XXXX/number:034XXXXXXX/Price:5000"
{{ '}' }}
✓ PaySim pose aussi un cookie jwtApiKey (durée 7 min) utilisé pour la connexion au hub SignalR. Ce cookie est HttpOnly et Secure.
Étape 2

Afficher le QR Code

Prenez le valueKey retourné et générez un QR code côté client. L'utilisateur scanne ce QR avec l'application PaySim mobile.

Exemple — TypeScript (qrcode)

TypeScript 
// npm install qrcode
// npm install @types/qrcode --save-dev
import QRCode from 'qrcode';

const valueKey = response.valueKey;

QRCode.toCanvas(document.getElementById('qr-canvas'), valueKey, {{ '{' }}
  width: 256,
  color: {{ '{' }} dark: '#000000', light: '#ffffff' {{ '}' }}
{{ '}' }});

QR Code affiché ici

Le QR Code contient toutes les informations du paiement :

  • id — identifiant du paiement PaySim
  • id_proj — identifiant de votre projet
  • actionkey — votre référence commande
  • reason — code unique de la transaction
  • number — numéro mobile money du vendeur
  • Price — montant à payer
Étape 3

Connexion au Hub SignalR

Votre frontend doit se connecter au hub SignalR de PaySim avec le cookie jwtApiKey et le paramètre type=project pour être notifié en temps réel du résultat du paiement.

WS https://paysim.runasp.net/payhubs?type=project&payId=VOTRE_ID_PAYMENT

Exemple — Angular (avec @microsoft/signalr)

TypeScript 
import * as signalR from '@microsoft/signalr';

const payId = 'VOTRE_ID_PAYMENT';

const hub = new signalR.HubConnectionBuilder()
  .withUrl('https://paysim.runasp.net/payhubs?type=project&payId=' + payId, {{ '{' }}
    withCredentials: true
  {{ '}' }})
  .withAutomaticReconnect()
  .build();

hub.on('PaymentSuccess', (success: boolean) => {{ '{' }}
  if (success) {{ '{' }}
    confirmerCommande();
  {{ '}' }}
{{ '}' }});

hub.on('Error', (message: string) => {{ '{' }}
  console.error('PaySim erreur:', message);
{{ '}' }});

await hub.start();
⚠ La session expire après 7 minutes. Si le paiement n'est pas effectué dans ce délai, redemandez un nouveau valueKey via /developer/info/setup.
Étape 4

Traiter le résultat

Quand l'acheteur scanne et confirme le paiement via l'app mobile PaySim, le hub envoie PaymentSuccess à votre frontend. C'est le signal pour confirmer la commande côté serveur.

1
Acheteur scanne le QR

L'app mobile PaySim lit le QR et affiche les détails du paiement à l'acheteur.

2
Acheteur envoie le paiement MVola

L'acheteur fait un transfert MVola/Orange/Airtel. L'app reçoit le SMS de confirmation et l'envoie au hub.

3
PaySim vérifie et valide

Le hub croise les données SMS avec la commande. Si tout correspond, il envoie PaymentSuccess: true.

4
Votre projet reçoit la confirmation

Votre listener SignalR reçoit l'événement et vous pouvez confirmer/livrer la commande.
